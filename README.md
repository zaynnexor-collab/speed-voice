# SPEED VOICE API

Backend de salas de voz com LiveKit e Supabase. Configure as variáveis SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET e FRONTEND_ORIGIN no Render. Não coloque segredos neste repositório.

A implantação inicial exige credenciais para ativar o áudio. A autenticação por convite deve receber testes de concorrência e proteção contra tentativas excessivas antes do uso em produção.
